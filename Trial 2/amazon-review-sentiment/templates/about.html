About This Project

The Amazon Review Sentiment Analyzer is a web application designed to help users quickly understand customer opinions about products sold on Amazon. By simply pasting the URL of an Amazon product page, the tool fetches recent reviews and performs sentiment analysis using Natural Language Processing (NLP).

The goal is to provide a summarized view of customer feedback, highlighting the overall sentiment (positive, neutral, negative) and identifying key topics or phrases mentioned in the reviews. This can be valuable for potential buyers researching a product or for sellers monitoring feedback on their items.

Technology Stack

This application leverages several technologies:

  • Python (Flask Framework)
  • Apify (For Review Scraping)
  • TextBlob (For Sentiment Analysis)
  • HTML5
  • CSS3
  • JavaScript (For Frontend Interactivity)

Review data is sourced directly from Amazon product pages via the Apify platform to ensure authenticity and relevance.

How it Works

  1. User enters an Amazon product URL.
  2. The backend (Flask app) receives the URL.
  3. The Apify service is called to scrape reviews for that product URL.
  4. Fetched reviews are cleaned and processed.
  5. TextBlob analyzes each review for sentiment polarity and subjectivity.
  6. Key phrases (noun phrases) are extracted from each review.
  7. Aggregate statistics (percentage of positive/neutral/negative reviews) are calculated.
  8. The results, including stats and individual review details, are sent back to the frontend.
  9. JavaScript displays the sentiment chart, statistics, and review cards dynamically.
